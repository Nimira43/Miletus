# 📘 Demo 2: Threshold‑Based Spike Detection & Local Median Replacement

## 🎯 Overview

Demo 2 introduces a different despeckling strategy:

1. **Detect spikes explicitly** using a threshold  
2. **Replace only the spike values** using a local median  
3. Leave all non‑spike samples untouched  

This approach is more targeted than full median filtering and is often used in:

- ECG/EEG artifact removal  
- Radar speckle suppression  
- Audio click removal  
- Sensor glitch correction  

It is computationally cheap and preserves the underlying signal far better than global smoothing.

---

## #️⃣ **Block 1 — Re‑Generating the Spike‑Corrupted Signal**

This block is identical to Demo 1’s first block:

```python
pnts = 1234
signal = np.mod(np.linspace(0,5,pnts)**2,5)

p = int(0.1*pnts)
spiketimes = np.random.randint(0,pnts,p)

signal[spiketimes] = np.random.rand(p)*100 + 10

plt.plot(signal)
plt.show()
```

### ✔ Purpose  

To recreate the same noisy test signal so Demo 2 can be compared directly with Demo 1.

### ✔ Insight  

This ensures consistency across demos and allows you to evaluate different despeckling strategies on identical data.

---

## #️⃣ **Block 2 — Empirical Threshold Selection**

```python
plt.hist(signal, 80)
plt.ylim([0,10])
plt.show()
```

### ✔ Purpose

To visually inspect the distribution of signal values and choose a threshold that separates:

- **Normal signal values**  
- **Spike values**  

### ✔ Insight

The histogram typically shows:

- A dense cluster of low‑amplitude values (the real signal)  
- A long tail of high‑amplitude values (the spikes)

This makes threshold selection intuitive.

---

## #️⃣ **Block 3 — Identifying Supra‑Threshold Spikes**

```python
thresh = 8
supra_threshold_idx = np.where(signal > thresh)[0]
100 * len(supra_threshold_idx) / pnts
```

### ✔ Purpose  

To detect all samples whose amplitude exceeds the chosen threshold.

### ✔ Insight  

This gives:

- A list of spike indices  
- A percentage of the signal corrupted  

This is useful for diagnostics and for tuning the threshold.

---

## #️⃣ **Block 4 — Visualising Detected Spikes**

```python
plt.plot(signal)
plt.plot(supra_threshold_idx, signal[supra_threshold_idx], 'ro')
plt.show()
```

### ✔ Purpose  

To confirm visually that the threshold correctly identifies spike locations.

### ✔ Insight  

Red markers (`'ro'`) highlight detected spikes.  
This is a sanity check before applying corrections.

---

## #️⃣ **Block 5 — Local Median Replacement (Targeted Despeckling)**

```python
k = 7

for i in supra_threshold_idx:
    lowbnd = np.max((0, i-k))
    uppbnd = np.min((pnts, i+k))
    signal[i] = np.median(signal[lowbnd:uppbnd])

plt.plot(signal)
plt.show()
```

### ✔ Purpose  

To replace each spike with the median of its local neighbourhood.

### ✔ Why Median?  

Median filtering is ideal for impulsive noise because:

- The median is **robust to outliers**  
- Spikes do not influence the median  
- The underlying signal shape is preserved  
- Only corrupted samples are modified  

### ✔ Insight  

This is a **targeted median filter**, not a full sliding window median.  
It has several advantages:

- Faster than full median filtering  
- Leaves clean samples untouched  
- Removes spikes without blurring the signal  
- Preserves edges and structure  

This is a highly effective despeckling technique.

---

## 🧠 Summary of Demo 2

Demo 2 introduces a practical workflow:

1. **Visualise distribution → choose threshold**  
2. **Detect spikes → mark indices**  
3. **Replace spikes → local median**  

This is a classic approach in many real‑world systems where:

- Spikes are rare  
- Spikes are large  
- Spikes are easy to detect  
- Only corrupted samples need correction  

It is simple, fast, and preserves the underlying signal extremely well.
